# 前端说明

前端基于 Vue 3 + Vite，负责在建工程分析、预算立项分析、关键指标总览以及全局历史记录中心的交互与可视化展示。

## 启动

```bash
cd /Users/liangsha/Documents/zaigongcheng-web/frontend
npm install
npm run dev
```

默认开发地址为 [http://localhost:5173](http://localhost:5173)。

## 构建

```bash
cd /Users/liangsha/Documents/zaigongcheng-web/frontend
npm run build
```

## 页面结构

- `src/App.vue`
  负责系统导航、顶部状态模块、全局历史记录中心和三个主页面切换。
- `src/views/Dashboard.vue`
  在建工程分析页，包含目标输入、文件上传、指标卡、进度仪表盘、四类工程预警面板、工程合规核查、管理员排名和明细弹窗。
- `src/components/CompliancePanel.vue`
  工程合规核查卡片与明细弹窗，负责所选版本加载、管理员及状态筛选、逐项核实结果登记、Excel 导出。
- `src/views/Budget.vue`
  预算立项页，包含预算文件上传、指标卡、专业进度表和项目明细表。
- `src/views/KeyIndicators.vue`
  关键指标页，聚焦展示资本性支出进度、立项进度和综合转固率，并提供 AI 分析与重点工作维护。
- `src/api/index.js`
  前端接口封装，统一调用后端分析 API。

## 工程合规核查

`Dashboard.vue` 将当前上传版本 ID 传给 `CompliancePanel.vue`。组件从后端读取核查区间与结果，不在浏览器端重复计算筛选口径。核查规则见[指标口径](../docs/metric-definitions.md#工程合规核查)。

- 两张卡片主数字显示待处理数量（待核实＋发现问题），下方提供「已核实」「全部」入口；点击卡片默认只展示待处理，正常项保存后立即从默认列表移出。
- 明细按管理员、已保存状态筛选，逐项登记状态、核实日期与备注。选择已核实正常或发现问题时补入当日作为可编辑日期，后端校验非待核实状态必须有日期。
- 只有点击「保存核实结果」才写入本机数据库；保存一项不清空其他项目的未保存备注，重新上传报表后继续继承已保存结果。
- 切换版本会关闭明细窗口并重新加载，旧版本的迟到请求不能覆盖当前版本。新项目区间取所选版本，核实结果为当前登记结果，已核实存档及未结事项可跨期查询。
- 未结问题超过两个月或从报表中消失仍持续跟踪；关键字段变化后重新纳入待核实，并展示变化、上次状态、日期及原备注。已核实正常项目数据没变时不重复提醒。
- 导出包含两类完整清单及已保存结果，不受弹窗当前筛选条件影响。缺原始明细或加载失败时显示明确提示与重试，不回退为零项。
- 弹窗支持 Escape 关闭、焦点循环、关闭后恢复焦点及页面滚动。

接口封装位于 `src/api/index.js`：`getCompliance(recordId)`、`saveComplianceReview(recordId, kind, code, review)`、`exportCompliance(recordId)`。组件回归测试位于 `src/components/__tests__/CompliancePanel.test.js`。
