# 在建工程指标口径

## 投资结转率

本口径由用户于 2026-10-10 确认，依据仙桃分公司投资汇总截图（表内更新时间：2026年10月10日01点08分），用于后续在建工程分析和功能开发。

```text
投资结转额 = 单项总投资合计 - 累计资本性支出合计
投资结转率 = 投资结转额 / 本年预算 × 100%
```

投资结转率衡量尚未形成资本性支出的剩余投资规模相对于本年预算的比例。它与转固率是两个独立指标，回答“投资结转率”时必须采用上述口径。

### 字段与汇总规则

| 计算项 | 数据来源与含义 |
| --- | --- |
| 单项总投资合计 | 在建工程明细中的 `单项总投资`，按对应预算管理单位汇总 |
| 累计资本性支出合计 | 在建工程明细中的 `累计资本性支出`，包括以前年度和本年支出，不是 `本年累计资本性支出` |
| 投资结转额 | 两项合计相减；可用原表 `结转额（工程总投资-累计资本支出）` 的合计交叉核对 |
| 本年预算 | 对应年度、预算管理单位和数据时点的正式预算，截图字段为 `本年预算`；不能直接用看板目标值替代 |

- 分子与分母须对应同一预算管理单位、年度和数据时点。数据来源日期不同或范围不能确认时，明确标注差异。
- 先汇总金额，再计算比例；不能直接平均各项目或各单位的结转率。本年预算是单位层面的分母，不能在每个项目上重复累加。
- 不套用四类预警的过滤规则；四类预警排除已关闭、局房及基础设施工程的规则，不代表投资结转率也需要排除这些工程。
- 金额使用未舍入的原始值计算，分子、分母单位一致；展示可统一换算为万元，百分比保留两位小数。
- 本年预算缺失或为零时，结转率标记为不可计算并说明原因，不显示为 0%。没有可核实的本年预算时，不擅自使用 `target_value`、`year_target`、单项本年预计投资或设计批复金额作为分母。
- 分子出现负值时保留原始计算结果并核查原因，不擅自截断为零。比例可能超过 100%，不截断。

### 仙桃核对样例

以下金额单位为元，来自用户提供的汇总截图，仅作口径验证，不作为未来期间的固定参数。

| 项目 | 数值 |
| --- | ---: |
| 单项总投资 | 77,136,359.59 |
| 累计资本性支出 | 70,311,731.63 |
| 投资结转额 | 6,824,627.96 |
| 本年预算 | 21,291,913.00 |
| 本年累计资本性支出 | 21,257,180.67 |

```text
投资结转率
= (77,136,359.59 - 70,311,731.63) / 21,291,913.00 × 100%
= 32.052676…%
≈ 32.05%
```

## 完成率

上述截图的完成率采用以下口径：

```text
完成率 = 本年累计资本性支出 / 本年预算 × 100%
       = 21,257,180.67 / 21,291,913.00 × 100%
       ≈ 99.84%
```

完成率与投资结转率不能简单相加为 100%：前者使用本年支出，后者使用项目总投资减去历年累计支出，分子口径不同。

## 综合转固率

系统已有的综合转固率口径保持如下定义：

```text
综合转固率
= [1 - (期末在建工程余额 + 期末工程物资)
       / (本年累计资本性支出 + 期初在建工程余额 + 期初工程物资)] × 100%
```

综合转固率衡量在建工程资金转为资产的进度。投资结转额不是已转固金额，投资结转率不能用综合转固率替代。

## 后续使用

年底投资结转率目标为 **不高于 22%**（用户于 2026-10-10 确认）。结转率越低越好；年内高于目标提示与年底目标的差距，不直接判定年度考核不达标。「关键指标」页在顶部摘要右侧展示紧凑的独立指标块，保留下方四张环形指标卡和右侧面板的布局；点击“口径”查看计算、压降金额与数据日期。

```text
目标结转额上限 = 本年预算 × 22%
还需压降金额 = max(0, 当前结转额 - 本年预算 × 22%)
需下降百分点 = max(0, 当前投资结转率 - 22%)
```

上述差距按当前正式预算测算，预算或项目投资变化后应随数据重新计算。界面使用在建工程接口的 `metrics.transfer`（结转额，万元）与预算接口的 `budget_total`（正式本年预算，万元），不使用当期支出目标。两表日期来自各自的 `period.business_date`，不以上传日期替代。日期不同时在口径详情中标注，跨年度或日期未确认时不计算。

分析、报表或界面使用“结转率”时，明确指投资结转率，并注明本年预算的来源和数据截至日期。分析“转固率”时，使用综合转固率口径。

本页记录业务定义；新增计算、接口或界面时，应分别使用明确的结转率与转固率字段名，避免因现有代码中的 `total_transfer` 等命名而混用指标。
